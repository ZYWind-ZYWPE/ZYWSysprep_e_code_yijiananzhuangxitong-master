📋简介
易语言开发，PE环境使用的，系统部署小工具，PE 中运行软件、填写镜像路径、目标分区、引导分区、勾选需要功能，点击开始部署

✨功能
内置多种功能，大部分优化型功能还未看法完全和测试完全，由于本人无法验证部分功能是否可用，请各位大佬们帮忙试验下，谢谢！

🛠运行环境
系统：Win10/Win11 PE
依赖：cmd.exe、bcdboot、reg.exe
其他功能依赖已嵌入到软件内
